# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, insults and personal
attacks are not tolerated.

Report unacceptable behavior privately to the maintainer through
[a private security advisory](https://github.com/chavdar12/open-nginx/security/advisories/new) or the contact on
the maintainer's GitHub profile. Reports are kept confidential, and the maintainer may remove comments, close
issues or block anyone who breaks these rules.
